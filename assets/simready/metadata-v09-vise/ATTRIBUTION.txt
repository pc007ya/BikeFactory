Changes made 2026-10-27:
- Converted original composed OpenUSD visual geometry and PreviewSurface materials to GLB.
- Preserved geometry shape, normals, UVs and original material assignments; no decimation.
- Triangulated faces, generated tangent bases, joined static meshes and deduplicated identical materials.
- Centered horizontal bounds, grounded origin, changed Z-up to glTF Y-up; kept meter units.
- Resized original PBR textures to maximum 512 px and embedded all image data.
- Added a lossless gzip copy verified to decompress to identical GLB bytes.
- Omitted USD physics/semantics and articulated runtime behavior.

This is a generic bench vise visual model, NOT a bicycle welding fixture or alignment gauge.
