# G1 → G2 resolved decisions / synthetic three-station slice

All dimensions/times/personnel/material quantities are proposal assumptions, not plant observations. v0.10 untouched. No browser/3D acceptance claimed.

1. Shared contract: one integer-ms event clock. Modules own finite personnel/inventory/route rights; engine alone owns tasks, serial locations, stations/ports/buffers and movement. No module timers or outcome RNG.
2. Inputs and outputs are distinct: 8s skilled human loading/unloading tasks; 45/90/30s production times do not include these transfers. Service completion releases the worker, not the fixture. Actual transfer completion releases the fixture/input slot atomically.
3. One persistent AGV: reserves union of empty/loaded route before dispatch, does not reserve ports during travel. Source/destination port acquired only for actual 6s load/unload. Completed source load releases source slot; unload converts destination reservation to occupancy. Routes retain locks during occupied-edge closure; positions and remaining time freeze.
4. Human edges dual-direction exclusive; whole route atomically acquired, passed edges released. Core conservatively reserves remaining intersections as well. Waiting nodes are finite; this is logical topology safety, not geometry/clearance certification or multivehicle avoidance.
5. Personnel require skills and enough shift for approach+service+return. Arrival rechecks time; late unstarted tasks cancel untouched material/cart/station reservations. Physical HB return plus full scheduled rest duration required after delayed return. Rest eligibility has a real scheduler wakeup.
6. Replenishment has one finite cart and finite source. Ordinary parts deliver to PW; Q repair consumables deliver to QW. The assigned worker retains cart/task through empty return to H0. Position follows worker while moving. If an unforeseeable road closure overruns the shift while holding material, reserved destination unloading is explicit SAFETY_HANDLING_EXCEPTION, then return only; not hidden productive overtime. Overtime walking is separately counted, including late approach, not mislabeled as return-only time.
7. Rework maximum once, additional repair consumable required. Second failure remains traceable scrap; V1 clears Q-S into finite SCRAP storage. GOOD moves through Q-G to finite FG storage. No terminal objects disappear.
8. Initial fixture scenarios use only existing batch serials and consume their full BOM upfront; scrap also accounts for one repair package. Capacity/duplicates/unknown serials reject. Initial stock/finished state is explicitly synthetic, not fabricated prehistory. Initial completed counts are separate; complete lead-time KPI excludes prefilled jobs.
9. Canonical scheduler runs on domain events, shift/rest/return boundaries and explicit commands, never arbitrary render/advance endpoints. ADVANCED records are observer checkpoints, excluded from canonical domain-history comparison. Fixed caller runId supports deterministic tests; new real runs get unique metadata UUID and stable config hash/version. UUID does not influence dispatch or outcomes.
10. PAUSE has same-time priority; due completion actions remain queued with identity. RESUME commits once, then schedules. Port maintenance has owned interlock and freezes in-progress loading/transfer without releasing material or counting active work.
11. Replay stores committed state snapshots and pure interpolation between events. RecordedReplay never constructs a live engine or reruns dispatch, inventory, quality or routing. Same-ms ambiguity resolved by event sequence; time seek chooses last committed event at that time. Snapshots are SHA256-checked and defensive copies.
12. STALL is diagnostic, not success. Worker exclusions show NO_SKILL/BREAK/OFF_SHIFT/REST_REQUIRED separately; runUntil considers future shift and rest eligibility before declaring no autonomous progress. External blockage/absent resources require an explicit changing command or changed new scenario.

G2 scope only: Node logic + trace records/tests. No PLC/MES, physical collision solver, full factory, public deployment, browser visuals, or claims of measured productivity.
