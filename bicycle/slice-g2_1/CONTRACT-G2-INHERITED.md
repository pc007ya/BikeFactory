# G2 module contract / 2026-10-31
Separate candidate; no v0.10 edits. All configuration synthetic. Modules plain ES modules, Node builtins only.
Time integer milliseconds, orchestrator controls time. Modules never advance clocks or create timers/random numbers. Mutations emit via supplied `(type,payload)=>void` callback; core captures current time and increasing seq. Each module exports snapshot() returning JSON-only deep clone and restore(snapshot). IDs stable. Failed reservations make no mutation. Release only verified owner. No implicit infinite resources.
Core owns workpiece position, task lifecycle, station/buffer slots, event queue and priority. Modules own worker roster/routes/material accounting. Core reserves all needed resources transactionally; on failure undo only unstarted reservations. Core logs command and state checkpoint for exact read-only replay; replay never re-dispatches. Completion time same as PAUSE remains queued until RESUME then executes once. Core events sorted by time, priority, stable ID.
Personnel API: new Personnel(config,emit); choose(skill,now,durationMs,targetNode) -> {workerId,travelMs,returnMs}|null; reserve(workerId,taskId,skill,now,durationMs,targetNode) -> boolean; arrive(workerId,taskId,node); begin(workerId,taskId); release(workerId,taskId,now); status(now); snapshot/restore. configure workers [{id,skills,node,shifts:[[start,end],...]}], graph via constructor config. May use routing module for path timing only but core owns actual path locks. choose must include return to HB, reject beyond shift. No duplicate worker assignments. Helpers query alternatives/reasons.
Inventory API: new Inventory(config,emit); reserveKit(owner,bom)->boolean; consumeKit(owner)->object; cancel(owner); reserveReplenish(owner,material,qty)->boolean; pickupReplenish(owner); deliverReplenish(owner); snapshot/restore; assertInvariants(). config {stock,capacity,external}. Kit consume transfers to held[owner] not destruction. Return reserve failure atomic, replenish source+destination capacity reserved; source decremented at pickup, line stock increment at delivery. External→inTransit→line accounting preserved. consumed/held car BOM remains tracked. Rework same reserveKit owner unique.
Routing API: new Routing(config,emit); plan(network,from,to,speed)->{nodes,edges,distance,durationMs}; reserve(owner,network,from,to,speed)->plan|null; release(owner); block(edgeId,reason); unblock(edgeId); canTravel(owner)->boolean; snapshot/restore; assertInvariants(). Undirected shared edge locks, names canonical sorted A|B; human/agv distinct networks. Atomic whole-route reservation, no partial acquisition. Core stops at last safe point if blocked; module provides locks and diagnostics, not movement. All owners persistent IDs. Node occupancy in core; module may reserve destination node to avoid collisions only if contract explicit.
