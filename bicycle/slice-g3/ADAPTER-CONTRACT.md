# Three-station G3 presentation candidate — read-only contract

2026-10-31. Synthetic proposal, not measured plant data. G2 files remain frozen at engine SHA f2666e2dfcbdac0f94dd91ede283f237a7e86051802ffc3a110c580c0633a59c. No Mac, no forbidden browser retry, no deployment/public preview. G3 actual pixels remain unverified in current environment.

## Architecture
1. Offline recorded runs generated by unchanged G2 (normal + finite-resource/quality/blocked/pause scenarios). Browser never loads a second simulation engine or changes recorded state.
2. `record-player.js`: browser-safe index of committed checkpoints + pure interpolation matching G2 RecordedReplay; no dispatch, stock mutation, RNG or independent process clock. Playback uses one cursor in recorded simulation milliseconds. Wall clock only advances that cursor at selected speed; pause fixes it.
3. `state-adapter.js`: pure `adaptState(state)` returns a detached render model; frozen input never mutated. No DOM, Three, Date, performance, random or timers. All movement/poses based solely on snapshot actions/positions/progress. Structured scene anchors are explicit presentation assumptions.
4. `scene.js`: `createSliceScene(THREE)` returns `{scene, update(viewModel), pickables, dispose, stats}`. No time argument, no loops/timers/DOM requirement. Node geometry tests work without GPU. Human/vehicle roots match adapter positions. Geometry preserves selection IDs.
5. `dashboard.js`: `mountDashboard(root,handlers)` returns `{update(viewModel,context),dispose}`. Plain textContent for data; accessible DOM controls, labels. User handlers only control playback/camera/selection, never mutate G2 state.
6. `app.js`: renderer, OrbitControls, playback cursor, scenario switching, selected ID/camera, UI glue. Single RAF, no fabricated simulation ticks.

## Coordinate/model conventions
Core planar [x,y] metres → Three [x,height,-y]. Three-station equipment centres P=[3,0,-6], A=[9,0,-6], Q=[15,0,-6]. Human paths at y9/operation y7.5, AGV paths y2/ports y4.5. No shared human/AGV edges. Exact default graph from G2 routing.js read-only.
`anchors.js` owned by adapter worker defines every buffer slot, fixture, storage and material rack transform with explicit `assumed:true`; these are presentation proposals, not validated construction geometry. Full bikes length~1.75m, wheel dia~.7m, employees eye~1.65m, AGV~1.9x.9m. No whole factory decorations beyond this slice.
Station input/fixture/output positions are distinct; during 8s SERVICE load/out or 6s vehicle load/unload, workpiece position interpolates between the actual source/destination anchors with action progress. Ownership remains authoritative until commit. Positions are visual handling-path assumptions, not new material movement events. Human roots retain authoritative core position; hand/tool articulation represents work, not extra resource assignment.
At a rendering checkpoint, every released serial has exactly one visual object, including GOOD awaiting exit and SCRAP; no duplicated fixture bike. Persistent V1 and W1/W2 always exist. Replenishment cart continuous position from state.cart. Material stock quantity/held/reserved/capacity labels read ledger; decorative rack bins must not imply additional stock.

## Tests vs real visual acceptance
Independent pure adapter tests use frozen snapshots from recorded normal/shortage/full/blocked/rework/pause runs, check unique visual ownership, capacities, continuous handling endpoints, root positions, stop/seek invariance. Geometry tests inspect finite bounds, anchors, model IDs and update/dispose, not pixels. DOM tests verify controls/state labels and no HTML injection, not browser layout.
Actual WebGL rendering, lighting, occlusion, selection hit regions, camera usability, mobile layout and video remain NOT VERIFIED. Only actual authorized browser render can close G3.

## Final presentation-only derivations
- `RecordPlayer.sample()` adds `presentation.slotAssignments` derived from reservation/occupancy history, plus retained last-travel `headings`. These never appear in G2, consume no resource, and cannot mutate the stored record. Raw `.at()` remains byte-structure equivalent to G2 replay.
- `vehicle.phase` retains production phase; `vehicle.status` prioritizes PAUSED / BLOCKED for operational UI and light color. Station PAUSED / INTERLOCK / BLOCKED overrides the active green light without resetting pose.
- `cart.heading` follows actual replenishment `task.worker`; cart root remains the authoritative coordinate. The cart geometry is offset 1.1 m behind that root, explicitly a tow-display assumption; it does not add a collision/planning footprint to G2.
- Fixed buffer positions are visual anchors; rack/slot height determines support legs ending at floor level. This is a numerical geometry check, not a pixel/physical safety acceptance.
- Exact event seek uses seq to preserve same-millisecond intermediate states. Time seek chooses the last committed event at that time. Resume from exact-event inspection clears seq and continues ordinary recorded-time playback; it does not execute a new production command.
