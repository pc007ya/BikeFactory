# G1 補充提案：接觸／輔助移轉／20秒工時／終端界線

2026-10-31。**示範設定迭代，不是實廠工時、設備採購規格或已通過G3。** 使用者授權小模組實作；本輪依整合審查修正呈現矛盾。原 G2 程式、原 8／6 秒紀錄與獨立證據保留，不以新結果覆蓋舊版。

## 1. 原矛盾與處理

- 操作點距原工件中心1.5m，手臂約.46m，不能真接觸：人根／路網不動，工作面呈現移到planar y7.10；指定真車架表面、掌球表面接觸，固定.24+.22m骨長，不拉長手臂。
- G2員工在操作點不跟著工件跨2.6m搬運：明示新增**操作員持續操控的輔助移轉治具提案**，不是徒手搬，也不宣稱原工廠就有機構。控制按鈕實際可達；無員工／無端口鎖不產生有人移轉。
- 工件直線加正弦高度會一開始下降穿入支撐：改為同一action進度的空載接近→垂直抬離→移動→垂直放下→空載回固定home。工件、托架、吊具不使用第二個時鐘。
- 舊站低座與AGV輪子確實相交；移除低座改真實平面標線，重排低支撐和側出口硬體。Q緩衝位移至y6.2／7.4，離開EXIT車路。P_OUT/A_IN兩槽呈現位調為y6.0／7.7，Q_IN為y6.0；固定通道v3避開旁槽與停靠載貨AGV。這些是展示幾何提案，不修改核心物件位置。
- 永久開口托架每個released序號恰一件，輪下留空，Q滾筒可接胎底；托架／吊架不是新增無限物料或獨立排程代理。支撐與接觸不代表已驗受力或安全。

移轉機構的各運動段按實際路程分配時間，cubic smoothstep零速度起停；有人移轉首尾各10%給到控制器／收手，中間才動機構。峰速是幾何路徑推導的**所需速度**，不是額定速度或驗收上限。尚未包含負載、慣性、夾持停留、扭矩、加速度／jerk限制和安全區域；實機設計仍可能要求更長工時。

## 4. 終端範圍：交接，不假造ASRS

FG／SCRAP只建**切片邊界接收輸送段＋開口界線**。工件保持載貨朝向、等高跨越界線；卸載action未commit前仍是V1／目的預留的權威帳務，不能提前當作已入庫。commit後從三站實體場景移到可選取的 `offSliceJobs` 有限台帳，包含初始預填序號。

不畫出六個倉庫槽的實際搬運、不新增虛構倉儲員工或ASRS。`在切片實體 + 切片外台帳 = 已投料序號` 且每序號唯一。倒放／seek可逆還原交接狀態。這是明示模型邊界，不是已建立完整終端倉儲物流。
