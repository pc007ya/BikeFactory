# 三站 G3／G2.1 呈現候選 — 尚未實畫面驗收

**不是整廠完工、已校準實廠數位孿生或已達參考影片效果。** 三站、六台示範自行車、兩名有限技能員工、一台持續 AGV、一台補料推車。站點、工種、工時、尺寸、數量及設備都是提案假設。

## 開啟與操作
可在支援 WebGL 的桌面瀏覽器**嘗試**開啟 `dist/START.html`。全部程式、MIT 函式庫及七情境紀錄內嵌；不需 CDN、外部模型或伺服器。尚未在真瀏覽器驗證開啟、畫面、效能或目標裝置相容性。WebGL 失敗時預計保留事件與指標並顯示錯誤；這只做 Node DOM 替身驗證，不等於瀏覽器測試。

預設暫停。播放 1–60×只改一個回放游標；時間軸可前後跳轉，精確事件序號區分同毫秒暫停與完成。拖曳旋轉、滾輪縮放；選工站、員工、AGV、推車或序號後按「選取近看」。切片外序號仍可查台帳，但不虛構倉內位置。

**唯讀紀錄**：不能在 HTML 裡改週期、派工、手駕或即時注入異常；不重跑排程、不另造動畫時間或生產成果。

## 實際實作範圍
- P 備料 → A 裝配 → Q 檢查；有限料位／預留、缺料等待、有限技能與班段、一次小返工、有限隔離／成品容量。
- 站內搬移是**員工持續操控的機械輔助治具提案**，有控制器、固定架、吊車、吊具及每序號永久開口托架；不是徒手搬運或既有實廠設備。
- 手臂長度固定 .24＋.22 m；工站真表面／把手接觸、全部階段仍要對新版實錄做幾何核查，不以隱藏 marker 或拉長骨骼假裝完成。
- 新站內移轉／AGV 裝／卸均 **30 秒**。共同平移／旋轉配時預算 .8 m/s、30°/s 是設計假設，**不是設備額定能力或安全認證**。前後機構移動不提前提交貨物、釋放員工或料位。
- 補料車有獨立 body center、heading、停泊位、把手、2 秒接手／脫離；員工推車往返、實際泊車後才走回自己的休息位。核心有時間的 CART／AGV TURN；堵路及暫停會凍結同一 action 的姿態與剩餘時間。
- 成品交接位卸完後，AGV **空車沿原支路倒退到 VJ，再以真 TURN 轉向**，避免在輸送台旁原地迴轉穿模。倒退姿態／里程仍由核心記錄，不是鏡頭或模型偏移。
- 人行藍線、AGV 青線、推車橘線，紅色封路。只有一台 AGV、一台推車，不稱多車避碰或交通安全驗證。
- FG／SCRAP 只建**切片邊界交接＋有限容量台帳**。完整跨界且 commit 後轉至切片外帳；不建倉儲搬運或 ASRS。切片內可見序號＋切片外帳恰等於已投料序號。

## 仍未驗收／刻意簡化
1. **沒有真 WebGL 截圖或錄影**。燈光材質、遮擋、自然動作、相機、點選、排版、FPS、記憶體與離線裝置相容性未驗。
2. 幾何採樣、真 triangle 距離、解析姿態與 DOM 替身不等於連續碰撞證明、人體工學、職安或機械可製造性。
3. 推車腳輪是可轉向腳輪提案；輪轉／轉向驅動、接地、滑移、負載慣性、力矩、加速度及 jerk 未模擬。AGV 的原地迴轉亦是明示軌跡假設，不是控制系統。
4. **補料拆箱／逐件上架未細分，屬有限台帳級服務**；C-P／C-Q 代表各站補料交付區，不聲稱人已逐件從推車搬至畫面每個料架。外部供應與終端倉儲位於切片邊界外。
5. 普通未附著員工的路段朝向仍離散切換；未建立足部接地、完整步態或人體自身碰撞模型。推車附著、轉向與接手／脫離姿態不能用此簡化掩蓋跳位。
6. Q 檢查與被動輪組支承為示意；沒有真扭力、感測器、完整輪組測試或現場資料接入。任意途中取消／安全救援未實作，不把未開始預留的取消當成完整救援功能。
