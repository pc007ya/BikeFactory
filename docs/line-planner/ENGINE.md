# 模擬契約與假設

此模組是未經實廠校準的串行產線規劃模型。每站的子工序依陣列順序完成；不含分岔、返工、搬運時間、換線、報廢或跨站共享資源。每個子工序有獨立同型機台池；相同 machineType 名稱不會自動合併資源。本站人員共享、無技能差異。

所有時間單位為秒。buffer 是站前等候件數，至少 1；加工及完成後堵塞的工件不占等候 buffer。完成件在下一工序／下一站可以接收前繼續占用原機台，但完成加工即釋放人員（blocking after service）。尚未完成加工的人員在故障與非班段也保留分配；故障／下班會暫停工時，修復／上班後續做。這是明示假設，不模擬加工途中故障時重新分配人員。完成後等待交接不占人力；進下一工序時重新取得該工序需求人力，避免上游完成件占滿人員而無法啟動高人力下游工序。

班段為全線共用、由 0 秒起算的絕對區間。故障是曆時指數 MTBF，修復是指數 MTTR，即使下班或機台空閒亦會發生；0/0 表示無故障。隨機數為固定種子加穩定工站／工序／機台索引的獨立 stream，新增機台不改變既有機台的故障序列。增加一台的敏感度在相同種子下重跑所有事件。它是單次情境比較，不是統計信賴區間。

到料間隔 0 表示無限外部供料、有限第一站 buffer 與投料上限。正間隔採供應背壓：第一站緩衝滿時等可接收後才投料，後續間隔從實際投料算起，不建立外部積壓帳。

完成件計數窗 (warmup, horizon]，時間積分窗 [warmup, horizon]，到終點立即截斷、不排空。跨暖機的在製品保留，暖機後完成件的 lead time 含其暖機前已經歷時間；meanLeadSeconds 是窗內完成件平均，不代表期末未完成件。completed 是全程完成數，observedCompleted 是窗內完成數。暖機起點同刻完成事件不計入 observedCompleted，終點同刻完成事件計入，避免相鄰觀察窗重複計件。期末在製品保留且 injected = completed + endWip。

wip 是觀察窗內時間積分／窗長；各站包含等候、加工、停機、堵塞的全部工件。busy/down/starved/laborWait/blocked/offshift 為所有機台各狀態的秒數加總，會等於機台數 × 觀察窗。非班段優先分類 offshift；班內故障為 down；完成等待為 blocked；有可接續工件但無可用人力的空機為 laborWait；無可開工件的空機才為 starved。

availability（uptime）= 班內未故障秒／排班秒；utilization = 班內加工秒／排班秒，兩者分母相同但意義不同。非班段故障不降低班內 availability。沒有排班秒時兩者回傳 0。線平衡是各站名義資源工時負載總和／（站數 × 最大負載），為描述性指標；瓶頸候選應搭配實際狀態、負載與增加機台後產出差異判斷。bottleneck 僅在加機後吞吐有正增益時回傳候選，否則為 null。受限於機台上限／總機台數或事件預算而無法跑的候選會跳過，列在 sensitivitySkipped（含 reason），不影響原情境結果。若敏感度全為零或全被跳過，不能斷言最大負載站是真瓶頸（可能是人力／供料／觀察期限制）。

安全工作預算：最多 30 站、60 子工序、200 機台、100000 投料，單次最多 100000 個事件或 5000000 機台×事件；超出直接拒絕／拋錯，請縮小情境。原始事件只保留前 3000 筆，KPI 積分仍計全程。

滾筒供料：可選 `conveyor.enabled`，與 AMR 互斥。外部有限存貨依 inletSeconds 入空首區；每區單件，以 length/speed 曆時運行、班外暫停，運行完成但無下區空位或首站緩衝時保留原件並計 blocked。區域完成／下游釋位同刻由引擎 settle 下游優先交接。出輸送末區才建立生產 job，因此 production conservation 不含輸送件；獨立 conveyor ledger 包含 source/conveyor/productionWIP/finished。觀察期輸送 WIP 與區域狀態積分只覆蓋 (warmup,horizon]，期末件不強制清空。`visible` 僅影響渲染，不能改事件與產出。未設輸送故障、滑移、載荷力學、PLC 或任意路由；首站內部轉運是抽象交接。

人工板車 `manualCart.enabled`：同時只能選 AMR／滾筒／板車之一；單車容量1、實體收料口1，工站既有邏輯buffer未改。實際首站 roster 人員從接任到回到原站位整趟保留（含抓放、推行、倒退牽回及班外暫停）；加工配置不得再次分配此 ID。來源有限，裝車才從來源提交車載，卸料完成才投產；收料口非空不派新趟以免單人自等待死鎖。跨班保存動作phaseU與料件，人員仍保留，恢復後續做。WIP積分及用工秒只覆蓋觀察窗，總推行／等候秒另標0–horizon。車上 WIP不混入原生產WIP；若已卸料但尚未加工，實體料台顯示同一件而非車上複製。
